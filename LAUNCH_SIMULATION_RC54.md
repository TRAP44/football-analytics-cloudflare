# RC54 — Launch Simulation & Conversion UX

## Цель

Проверить продукт так, как его увидит новый пользователь после большого размещения в СМИ, и убрать лишние шаги до первого полезного AI-результата.

Симулируемый путь: **media deep-link → /start → поиск клуба → матч → быстрый AI → полный AI → новости → возврат**.

Это release-сценарий и regression-контракт. Он не подменяет реальные production-метрики: после публикации фактическая конверсия берётся из first-party `growth_events`.

## Сценарий нового пользователя

1. Пользователь приходит по `?start=media__source__launch__article1`.
2. Бот сразу предлагает написать клуб или нажать «🔎 Найти матч».
3. Пользователь пишет «Реал», «МЮ», «Бока Хуниорс», «Аль-Наср» или другой клуб.
4. Сначала проверяются матчи дня; затем глобальный team search.
5. Для известного top-club intent допускается небольшой резерв поиска при низкой квоте; результат кэшируется на 24 часа.
6. При временной недоступности provider UI показывает «Клуб распознан», а не ложное «ничего не найдено».
7. После выбора матча быстрые AI-блоки работают в Telegram.
8. Только «Полный AI-разбор» открывает Mini App на выбранном fixture.
9. Новости остаются в Telegram. «Проверить ближайший матч» пишет `news_return`, затем обычный `match_open`.

## Блокеры конверсии, закрытые RC54

- непонятный первый экран;
- двухсимвольный известный alias не проходил client gate;
- top-клуб исчезал при низкой квоте API;
- пустой результат маскировал распознанный клуб;
- переход новости обратно к матчу не измерялся;
- launch analytics ограничивалась первыми 1000 событиями без полноценной пагинации.

## Нагрузочная модель

- canonical top-club query кэшируется 24 часа;
- high-intent fallback расходует резерв только для распознанного клуба;
- неизвестный короткий запрос остаётся fail-closed на backend;
- launch-funnel читает до 10 000 строк страницами;
- при достижении лимита ответ ставит `truncated=true`.

## Метрики

Основная воронка: `entry → search → match_open → quick_ai → full_ai`.

RC54 дополнительно возвращает `bottleneck`, `returnLoop.newsOpen`, `returnLoop.newsReturn` и `returnLoop.conversionPct`.

## Приёмка перед СМИ

- проверить media deep-link новой учётной записью;
- проверить «МЮ», «Реал», «Бока Хуниорс», «Фламенго», «Аль-Наср», «Интер Майами»;
- открыть матч и быстрый AI;
- открыть полный AI и проверить выбранный fixture;
- открыть новости любимой команды → «Проверить ближайший матч»;
- проверить `news_return`, bottleneck, Status, Privacy и Terms;
- не интерпретировать regression simulation как фактическую production-конверсию.
