# RC70 — Smart News Match Linking

## Цель

RC69 превратил новости Telegram в измеримый AI-канал. RC70 делает следующий шаг: каждая новость связывается с тем матчем, для которого она наиболее релевантна по времени и футбольному контексту.

## Как выбирается матч

Для новости учитываются:

- время публикации;
- время fixture;
- LIVE / предстоящий / завершённый статус;
- расстояние между публикацией новости и матчем;
- тип новости.

Новости о травмах, дисквалификациях, составе, судье и погоде получают дополнительный приоритет для предстоящего матча, потому что эти события чаще относятся к предматчевому контексту.

Завершённый матч не выбирается вместо доступного предстоящего fixture.

## Персональные новости клуба

Список матчей уже загружается существующим `botTeamIdMatches`. RC70 не создаёт дополнительный provider-запрос для каждой статьи.

Каждая из первых четырёх новостей отдельно получает свой `newsRelevantFixture`. Поэтому две статьи с разными датами могут вести в разные матчи одного клуба.

В сообщении появляется:

- `🎯 Матч: Команда A — Команда B`;
- временной контекст относительно публикации;
- `🧠 Что проверить` со списком факторов, которые могли измениться.

## Общие новости

Если fixture заранее неизвестен, callback содержит только:

- безопасный team token из существующего каталога;
- UTC-день публикации в формате `YYYYMMDD`.

Заголовок статьи, URL и произвольный текст в callback и growth analytics не попадают.

После явного нажатия пользователя FM AI использует существующий team-search flow, получает доступные матчи и выбирает fixture относительно даты новости. Если smart-link невозможен, остаётся прежний поиск.

## Что AI предлагает перепроверить

Примеры:

- травма / дисквалификация: состав, глубина скамейки, баланс сил, рынок;
- состав: стартовый XI, роли, вероятности, рынок;
- судья: карточки, фолы, пенальти, темп;
- погода: темп, поле, интенсивность, тоталы;
- тренер: схема, стиль, неопределённость, форма.

Новость по-прежнему не меняет прогноз автоматически.

## Аналитика

`news_ai_intent` с прямым smart fixture содержит только технический признак `linking=smart_fixture`.

Launch Funnel показывает число пользователей, перешедших из новостей через smart fixture.

## Supabase и provider safety

Новая Supabase migration не нужна.

Для новостей избранного клуба используются уже загруженные fixtures. Для общих новостей запрос к матчам выполняется только после явного AI-нажатия пользователя и проходит существующие quota/cache guards.

## Production gate

RC70 требует:

- deterministic `smartNewsMatchLinkDrill`;
- regression test `smart-news-match-linking-rc70.test.js`;
- полный test suite;
- `verify:release`;
- Worker dry-run;
- production post-deploy smoke.
