# RC63 — Post-Match Return Loop

## Цель

Замкнуть пользовательский цикл после анализа матча: FM AI автоматически возвращает пользователя в Telegram после финального результата и показывает короткое сравнение «что было до матча → что произошло».

## Кто получает сообщение

Только пользователь, у которого есть запись в `analysis_history` по этому матчу. Простое открытие ленты, поиск команды или просмотр новости не подписывает пользователя на post-match return.

Матч должен быть старше 105 минут от времени старта и не старше 18 часов. Отправка происходит только после `model_predictions.status = settled` и наличия фактического счёта.

## Подтверждение результата

Если immutable prediction ещё ожидает settlement, RC63 может сделать экономный `/fixtures?date=...` probe. Probe:

- работает только при безопасном остатке API-Football;
- группирует несколько матчей одной даты в один запрос;
- кэшируется на 30 минут;
- ограничен максимум двумя датами за один запуск;
- не запускается, если нет pending-прогнозов анализированных матчей.

## Сообщение

Telegram показывает:

- команды и финальный счёт;
- сохранённый предматчевый AI-сигнал, если он есть;
- основной исход модели и его вероятность;
- фактический исход;
- совпал ли главный исход;
- кнопку `🧠 Открыть итог AI`.

Кнопка открывает существующий RC62 post-match review в чате и не списывает новый AI-анализ.

## Anti-spam

- один и тот же user + fixture имеет persistent delivery marker в `analysis_cache`;
- claim создаётся атомарно через `resolution=ignore-duplicates`;
- зависший claim старше 15 минут автоматически восстанавливается;
- после успешной отправки пользователь получает 30-минутный cooldown;
- за один scheduler pass одному пользователю отправляется не более одного итога;
- Telegram 403 автоматически отключает дальнейшие post-match сообщения.

## Управление пользователем

В уведомлении есть `🔕 Не присылать итоги`. Отключение хранится в persistent cache. После отключения бот показывает кнопку `🔔 Включить обратно`, поэтому настройка обратима.

## Аналитика

`post_match_return_sent` фиксирует доставку, а `post_match_return_open` — открытие итогового AI review. Это позволяет измерять реальный возврат после матча без хранения текста пользовательских запросов.

## Production gate

`postMatchReturnDrill` проверяет eligible / pending / too-early / message callback. RC63 требует зелёные regression tests, release verification, Worker dry-run и post-deploy smoke.
