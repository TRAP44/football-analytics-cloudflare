# RC72 — News Impact Decision Card

## Цель

RC71 умеет честно сравнивать AI-снимок до новости с новой перепроверкой. RC72 превращает технический delta в понятное решение прямо в Telegram.

## Четыре основных состояния

- 🔴 **Существенное изменение** — свежая перепроверка обнаружила заметный сдвиг входных данных AI.
- 🟡 **Изменились детали** — отдельные данные поменялись, но основной сценарий не сдвинулся существенно.
- 🟢 **Сценарий стабилен** — значимых изменений после новости не найдено.
- 🟦 **Причинность не подтверждается** — нет корректного снимка до новости, поэтому нельзя честно приписывать изменение новости.

Также предусмотрены состояния без baseline и временно недоступной перепроверки.

## Действия

Кнопки Telegram зависят от результата.

Для существенного изменения:
- открыть обновлённый полный AI-разбор;
- проверить составы;
- проверить рынок.

Для частичных изменений:
- открыть полный разбор;
- повторить AI-проверку.

Для стабильного сценария:
- вернуться к новостям;
- при желании открыть полный разбор.

Если сравнение невозможно, интерфейс предлагает повторить проверку или использовать текущий анализ как новую базовую точку.

## Causality guard

RC72 не утверждает, что новость вызвала изменение прогноза. Формулировки говорят о совпадении по времени и результатах перепроверки входных данных.

Если сохранённый AI-снимок не старше новости, пользователь явно видит статус «Причинность не подтверждается».

## Аналитика

В существующее событие `news_impact_delta` добавляется только категориальное поле `decision`:

- `material`;
- `detail`;
- `stable`;
- `guarded`;
- `baseline_missing`;
- `unavailable`.

Текст новости и пользовательский контент не сохраняются.

Admin Launch Funnel показывает агрегированные количества decision states.

## Supabase

Новая миграция не нужна: используется существующее `growth_events.metadata`.

## Production gate

RC72 требует deterministic `newsImpactDecisionDrill`, regression tests, release verification, Worker dry-run и production smoke.
