# Supabase — Football Analytics RC99

Эта папка заменяет набор SQL-файлов в корне репозитория.

## Новый Supabase-проект

Запустите **только** `baseline.sql` на пустом проекте.

`baseline.sql` содержит исторический baseline v6.9 и все обязательные изменения v6.10 → v6.15 в правильном порядке.

## Существующий Supabase-проект

Не запускайте `baseline.sql` поверх рабочей базы.

Перед изменениями сделайте backup и применяйте **только отсутствующие** файлы из `migrations/` по порядку:

1. `v6_9.sql`
2. `v6_10.sql`
3. `v6_11.sql`
4. `v6_11_1.sql`
5. `v6_12.sql`
6. `v6_13.sql`
7. `v6_14.sql`
8. `v6_15.sql`

Уже применённую миграцию повторно не запускайте без отдельного rollback-плана.

## Исторический baseline

`history/baseline_v6_9.sql` сохранён только для аудита и воспроизводимости RC17. Для новой установки используется `baseline.sql`.

## Безопасность

Backend-таблицы и RPC должны оставаться закрытыми для `anon` и `authenticated`; Worker работает через service-role/secret key. После изменения схемы проверьте RC Regression и backend security contract.
