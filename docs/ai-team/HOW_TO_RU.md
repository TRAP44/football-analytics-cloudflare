# Как работать с Claude и Codex вместе — инструкция для Сергея

## Как это устроено

```
            Сергей (ставит задачи, мержит)
              /                     \
      Claude (claude/*)        Codex (codex/*)
              \                     /
        GitHub: TRAP44/football-analytics-cloudflare
        AGENTS.md — общие правила
        docs/ai-team/BOARD.md — кто что делает
        docs/ai-team/HANDOFF.md — записки друг другу
```

Claude и ChatGPT не общаются напрямую — они работают в **одном репозитории** и «разговаривают» через код, доску задач, журнал и ревью Pull Request'ов.

## Настройка (один раз)

1. **Смержить PR `claude/ai-team-setup`** — после этого правила и доска появятся в `main`.
2. **Подключить Codex к репозиторию:** в ChatGPT открой Codex, подключи GitHub и выбери репозиторий `TRAP44/football-analytics-cloudflare`.
3. **(По желанию) Автоматическое ревью от Codex:** в настройках Codex, в разделе ревью кода, включи автоматическое ревью для этого репозитория. Тогда Codex сам будет проверять каждый новый PR.
4. Claude уже имеет доступ к репозиторию через Claude (claude.ai) — достаточно попросить его поработать с проектом.

## Как давать задачи

**Шаг 1.** Впиши задачу в `docs/ai-team/BOARD.md` (или просто скажи ассистенту — он впишет сам).

**Шаг 2.** Дай задачу одному из ассистентов. Шаблон сообщения:

> Возьми задачу «…» из docs/ai-team/BOARD.md. Работай по правилам AGENTS.md: отдельная ветка, проверки, PR, обнови BOARD и HANDOFF.

**Шаг 3.** Когда появился PR — отдай его на ревью **другому** ассистенту:

- PR от Claude → в комментарии к PR напиши `@codex review`.
- PR от Codex → напиши Claude: «Сделай ревью PR #номер по правилам AGENTS.md».

**Шаг 4.** Автор исправляет замечания. Можно прямо в PR попросить Codex: `@codex исправь замечания ревью`.

**Шаг 5.** Ты смотришь PR и мержишь. **Помни: merge в `main` = деплой в production.**

## Как делить работу (рекомендация)

Чтобы ассистенты не мешали друг другу, давай им задачи в разных частях проекта одновременно. Например:

| Claude | Codex |
|---|---|
| Бэкенд, данные API-Football, логика прогнозов (`src/`) | Интерфейс Mini App, дизайн, экраны (`public/`) |
| Тесты, безопасность, Supabase | Тексты, публикации для канала |

Это не жёсткое правило — главное, чтобы два ассистента одновременно не правили одни и те же файлы.

## Полезные приёмы

- **«Второе мнение»:** попроси одного придумать решение, а другого — найти в нём слабые места до того, как писать код.
- **Большая задача:** попроси одного ассистента сначала разбить её на мелкие задачи и записать их в BOARD, потом раздавай по одной.
- **Если ассистенты противоречат друг другу** — решение за тобой. Запиши его в HANDOFF, чтобы оба его видели.
