# Проверка Telegram перед выпуском

Полный набор `npm test` и `npm run test:review-tail` обязателен в Quality и повторяется перед deployment. Падение любой команды блокирует выпуск.

## Облачная среда и браузер

На Node.js 22 при необходимости используйте `NODE_USE_ENV_PROXY=1` для доступа через прокси среды. Для Chromium задайте `CHROME_PROXY_SERVER` как HTTP/HTTPS URL прокси без учётных данных. Пример: `CHROME_PROXY_SERVER="$HTTPS_PROXY" node scripts/bottom-nav-render-smoke.js`. Не публикуйте значения переменных с учётными данными.

Прокси должен иметь доверенный Chromium сертификат CA. Проверка не отключает TLS. `ERR_CERT_AUTHORITY_INVALID` означает необходимость установить доверенный CA в хранилище браузера средствами администрирования среды; обход проверки сертификатов не подходит. Для локальной проверки интерфейса не нужен доступ к production-секретам.

## Реальная пользовательская проверка

Используйте отдельный тестовый аккаунт Telegram и выполняйте только действия, которые согласованы для него. Не передавайте initData, токен бота или другие секреты в чат.

1. Откройте Mini App из бота. Проверьте первый запуск, закрытие и повторное открытие, кнопки навигации и возврат назад.
2. Найдите известную команду, откройте матч и центр матча. Проверьте отсутствие повторного запроса AI при простом просмотре.
3. Запустите один AI-анализ доступного матча. Зафиксируйте результат и расход квоты, затем проверьте историю и повторное открытие результата.
4. Добавьте и удалите команду из избранного. Убедитесь, что состояние сохраняется после повторного открытия.
5. Для согласованного тестового матча установите напоминание и проверьте доставку, затем удалите его.
6. Подтвердите отмену invoice без списания. Покупку за реальные Stars выполняйте только после отдельного согласования суммы, тарифа и аккаунта. Проверьте применение entitlement и отсутствие повторного списания при повторной доставке события оплаты.
7. Публикацию в канал проверяйте только в согласованном тестовом канале. Зафиксируйте доставку и отсутствие дубликата.

Для каждого пункта сохраните дату, версию приложения, ожидаемый и фактический результат без персональных данных и секретов. Автоматические тесты не заменяют подтверждение этих реальных действий.
