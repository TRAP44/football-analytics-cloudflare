# Аудит ответов Telegram-бота — 14.10.2026

Проверены шаблоны и изолированные интеграции, не настоящая отправка пользователям. Картинка с длинными названиями отрендерена в PNG и просмотрена. Telegram-клиент и токен бота в этой среде недоступны.

| Поверхность | Что проверено | Результат |
|---|---|---|
| Матчи / LIVE | Кнопки, изменение минуты, счёта, пустой список, отсутствие изображения | Прежние регрессии проходят, счёт/статусы не выдумываются, callback сохранены |
| PNG-карточка | Два длинных названия рядом со счётом | Найдено обрезание до 21 символа вместо 16. Исправлено, до двух коротких строк на команду, кеш v3 |
| Поиск матчей | Длинные названия обеих команд, emoji | Ранее обрезалась общая строка и терялся соперник; теперь ограничены обе команды отдельно, UTF-16 пара не разрывается |
| Мои команды | Пустой список, длинное название, выбор клуба | Короткая инструкция с ☆, многоточие для длинного имени, ID кнопки сохранён |
| Матчи клуба | LIVE, завершённые и недоступные матчи | LIVE с минутой, завершённый явно подписан; короткий пустой ответ и повторное действие. HTML статуса экранирован |
| Общие и клубные новости | Пустая лента, HTML/URL, прогнозные страницы, длинная кнопка матча | Действующие проверки фильтров/ссылок проходят. В длинной кнопке клуба сохраняются обе команды |
| Утренние новости | Короткая подборка, безопасные ссылки, пустой результат | Действующие проверки проходят, пустое сообщение не отправляется |

Изменения касаются подачи. Не менялись число выбранных матчей, сортировка, callback, расписание, квоты и права. Новых запросов к API-Football и зависимостей нет. public/ не менялся.

Отдельный найденный пробел: кеш матчей любимого клуба — 120 минут; нормализованная карточка клуба не сохраняет счёт. Это задача свежести/данных, записана на BOARD; в текущий PR не включена. Следующий функциональный шаг — проверить LIVE любимого клуба, используя существующие общие снимки, прежде чем сокращать кеш или добавлять запросы.

После merge/deploy проверить на телефоне: поиск двух клубов с длинными названиями, клубные новости, пустые «Мои команды», LIVE и завершённый матч клуба. Для PNG дождаться фонового запуска с новым кодом (кеш v3). Старые Telegram-сообщения не переписываются.
