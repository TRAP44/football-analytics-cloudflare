## Привязка и фазы

Выбираются только обычные английские полные версии, исключая Hindi/Vertical/клипы. Требуются точные ordered team names и сезон2026-27 в anchored заголовке. Для LIVE дополнительно Gameweek совпадает с каноническим туром. Для FULL REPLAY счёт совпадает с независимо подтверждённым итогом FT/AET/PEN. Первая строка описания отдельно подтверждает обе команды, тип LIVE/Full Match Replay, положительный Match N, дату в Asia/Kolkata и English. Match N — порядковый номер матча источника, он не подменяет Gameweek. Второй такой заголовок, конфликт даты/языка/команд или недостающие поля отвергаются. Описание сокращается до этой строки только после проверки исходных метаданных; consumer проверяет его снова.

У наблюдённых записей студия начинается раньше матча: scheduled13:30, actual13:28:58 при kickoff14:00UTC. Только ISL допускает старт от kickoff−45мин до kickoff+5мин. Это одинаково применяется к scheduled/actual start у producer и consumer. Прежние общие допуски15мин для scheduled и30мин для replay не ослаблены. Запись требует настоящих actualStart/actualEnd и длительности60–240мин; название или duration не превращают NS в завершённый матч. Закрывшийся английский эфир может лишь инициировать отдельное каноническое перечитывание дня через15мин, даже если у NS ещё нет счёта; выдуманный FT/счёт не сохраняется.

ISL сохраняет проверенные broadcastKind/videoStream. Cached upcoming после пересечения scheduledStart остаётся запланированным. Только свежие live metadata с действительным actualStart<=now без actualEnd могут означать текущий эфир. Предстудийный эфир не меняет канонический статус матча с NS на1H. Generic legacy YouTube-контракт сохранён. У завершённого эфира replay появляется только после канонического финального статуса.

## Запросы и совместимость

Восьмой канал: до10 результатов отдельно live/upcoming, поиск раз в12ч; до20uploads раз в15мин. Ранее найденные видеозаписи сохраняются в fixture bindings и продолжают проверяться независимо от исчезновения из первых20публикаций. Новых provider-запросов на зрителя нет.

Discoveryv5 хранится отдельным ключом; старые v4/v3/v2/v1 читаются для миграции и не переписываются, чтобы сохранить откат. Максимум8каналов/3full-канала,370uploadID+100searchID=470feedID, плюс200связанных и20ручных: всего690уникальныхID,14пакетов metadata. Максимум28YouTube запросов/run, включая6search+8uploads+14metadata. Реальный транспорт на таком максимуме проверен тестом, а не только формулой.

Расчётный худший расход: старые8540 +400search +96uploads +288metadata =9324units/day при стандартной квоте10000. Запас676 разделяется с административными проверками; это не измерение остатка квоты аккаунта. Наблюдаемые запреты и quota403 не обходятся. Интервалы остальных каналов сохранены. API-Football по-прежнему максимум2даты/run и16попыток/day с общим дневным счётчиком, минутным лимитом и FREE-резервом. Добавление league323 расширяет coverage; старые подтверждённые bindings сохраняются, новые дни подгружаются в существующем бюджете.

Новых SQL/permissions/frontend assets нет: существующий launch154 понимает новые YouTube-источники. Русское название «Суперлига · Индия» приходит из проверенного серверного каталога. Число реально опубликованных новых матчей фиксируется только после CI, выпуска и non-skipped фонового обновления; будущие эфиры нельзя выдавать за уже идущие.
