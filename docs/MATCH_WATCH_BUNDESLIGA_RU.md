# Официальные обзоры Бундеслиги

Проверка 29 октября 2026 года. Официальная страница https://www.bundesliga.com/en/bundesliga содержит ссылку на https://www.youtube.com/@bundesliga/videos. Google API подтвердил ID канала `UC6UL29enLNe4mqwTfAyeNuw`. Запуски 40941001362, 40941321457 и 40941524317 независимо получили метаданные 20 видео и матчи за 25, 24 и 23 октября. Используемые поля и ссылки на исходные запуски сохранены в `test-support/fixtures/bundesliga-watch-sources.json`.

В наблюдениях есть восемь подходящих обзоров. У них разрешены встраивание и просмотр в RU/KZ/BY по метаданным Google. Полные эфиры канала недоступны в этих странах и имеют `embeddable=false`, поэтому не добавляются. Сборники, короткие клипы и прямые эфиры не считаются обзорами отдельного матча.

## Сопоставление

Одновременно должны совпасть:

- официальные названия двух клубов и тур в заголовке;
- те же два клуба и тур в первой строке описания;
- отдельная строка описания с двумя клубами, туром и полным сезоном;
- независимый завершённый матч API-Football в Бундеслиге, ID лиги 78.

Сокращения клубов разрешены только для проверенных ID команд. Нет нечёткого поиска или удаления произвольных приставок. Конфликтующие сезон или тур отвергаются. Например, «FC Bayern» связано с командой 157, «Bayer 04 Leverkusen» — с 168; это разные клубы.

Бундеслига публикует пятничные матчи вместе с воскресной подборкой: в наблюдении Stuttgart–Mönchengladbach разница составила 52,5 часа. Только для этой политики допускается публикация в течение 72 часов после начала матча. У остальных источников сохранён предел 48 часов. Семидневное окно просмотра и остальные проверки времени не изменяются. Заголовки без сезона всё равно требуют точного сезона и тура в независимой строке описания.

Исходные метаданные проверяются полностью, затем из описания сохраняются только строки, нужные для повторной серверной проверки. На выдаче повторно проверяются матч, источник, срок действия, страна и разрешение на встраивание. Новые пользовательские запросы к YouTube или футбольному провайдеру не добавляются.

## Бюджет и откат

Новый канал проверяется раз в 10 минут. Для семи каналов пределы составляют 430 ID из лент/поисков + 200 ранее связанных + 20 ручных = 650 уникальных ID, пакеты по 50. Максимум — 24 запроса YouTube за запуск. Расчётный максимум за сутки: 3200 единиц поиска + 1596 загрузок лент + 3744 проверки метаданных = 8540. Это расчёт для стандартной квоты 10000, не измерение настроек аккаунта.

Сбой новой ленты не удаляет другие лиги. Попытка записывается до запросов, а сохранённые видео независимо перепроверяются. Новый снимок discovery v4 мигрирует v3/v2/v1, не записывая поверх них: старые версии производителя могут использовать прежние снимки при откате. Совместимый индекс J1/ручных записей сохранён.

Футбольный источник сохраняет пределы: до двух дат за запуск и 16 попыток в сутки, общий минутный лимит, резерв бесплатного тарифа и паузу после ограничения. Новая лига попадает в общие пакетные запросы; нет запроса на каждый матч или зрителя.

## Проверки и границы доказательства

Фикстура — очищенная проекция наблюдений Google и отдельно проверенных матчей, не полный исходный ответ Google. Список стран ограничен инспектированными территориями и не означает всемирных прав. Тестовый HTTP-транспорт восстановлен из этих наблюдений; физическое воспроизведение в Telegram не проверялось.

Проверены восемь положительных соответствий, неподходящие клипы/архивы/эфиры, неправильные клубы/сезон/тур, задержка публикации, повторная проверка сохранённого описания, отзыв видео, отказ ленты, интервал 10 минут и расчёт квоты. Общие проверки приватности, географии и возраста сохранены. Независимое ревью сверило видео, канонические матчи и официальный footer.

Локально прошли Node 22 npm ci, check, lint, release 989/989, полный набор 4787/4787, security scan, privileged audit, verify:release и сборка Worker. Независимое ревью — 73/73.
