# Гербы команд в Telegram-боте

Поддержка относится к тексту списков «Матчи» и LIVE. В HTML используется `<tg-emoji emoji-id="…">⚽</tg-emoji>` рядом с именем команды. Имена, счёт и минуты остаются обычным текстом; кнопки открытия матча сохраняют прежние callback и подписи. Это не меняет Mini App или посты канала.

## Условия Telegram

[Официальный Bot API, HTML style](https://core.telegram.org/bots/api#html-style): custom emoji разрешены ботам с дополнительным именем, купленным на Fragment, либо в прямых сообщениях бота в личные чаты, группы и супергруппы, если у владельца бота есть Telegram Premium. Premium у получателя сообщения не указан как условие отправки. Условия проверены 14.10.2026. Возможность публикации в канале отдельно не предполагается.

## Подключение

1. Выбрать набор гербов `https://t.me/addemoji/<имя набора>`. Нужен именно custom emoji set, а не обычный sticker set.
2. Получить набор методом [getStickerSet](https://core.telegram.org/bots/api#getstickerset) с текущей авторизацией бота. Каждый элемент `stickers` содержит `custom_emoji_id`; сверить изображение с конкретным клубом. Название/цвет сами по себе не подтверждают принадлежность.
3. Составить JSON-объект: ключ — ID команды API-Football, значение — **строка** `custom_emoji_id`. Большие emoji ID нельзя хранить JS-числом: теряется точность. Пустая безопасная конфигурация — `{}`. Production ID в репозитории не выдумываются.
4. Задать `TELEGRAM_TEAM_EMOJI_IDS` в переменных Worker и включить `TELEGRAM_TEAM_EMOJI_ENABLED=true` после проверки прав и соответствий. По умолчанию функция выключена. Не передавать токен бота в чат или документацию.
5. В тестовом личном чате открыть «Матчи» и LIVE: проверить оба герба, неизвестную команду и кнопки. Локальные тесты проверяют HTML и отправку с подставными интеграциями; реальное отображение гербов требует Telegram и настоящих ID.

## Безопасное поведение

- Неизвестный клуб при включённой функции получает ⚽; при выключенной — прежнее оформление без префикса.
- Некорректная JSON-конфигурация не ломает списки; неверные значения исключаются. Карта ограничена 500 командами и 50 КБ.
- При явном ответе Telegram 400, относящемся к custom emoji/Premium/Fragment, выполняется одна отправка без тегов emoji. При timeout, сетевой ошибке, 429/5xx или иной ошибке 400 повторной отправки нет.
- Дополнительных запросов к API-Football или Telegram за гербами на каждый просмотр нет: карта читается из конфигурации.
