# RC69 — Telegram News Conversion Engine

## Цель

Новости остаются в Telegram-чате, а Mini App остаётся минималистичным AI-инструментом анализа матча. RC69 связывает эти две части без превращения Mini App в новостную ленту.

## Что изменилось в Telegram

Каждая новость теперь содержит:

- категорию и уровень влияния;
- объяснение «почему важно»;
- строку «🧠 Что проверить»;
- ссылку на первоисточник;
- AI-кнопку, когда новость можно связать с известным клубом или ближайшим матчем.

Для персональных новостей клуба, когда ближайший fixture уже известен, кнопка ведёт сразу в короткую AI-оценку матча. Повторный поиск не нужен.

Для общих новостей FM AI пытается безопасно распознать клуб из существующего каталога топ-команд. Кнопка запускает существующий поиск ближайшего матча клуба, а не создаёт прогноз по одному заголовку.

## Trust gate

RC69 не отменяет RC52. Высоко-impact новость из обычного веб-источника по-прежнему понижается до medium и помечается как требующая подтверждения.

Новость сама по себе не меняет прогноз. Пользовательский текст прямо объясняет, что AI сверяет новость с футбольными данными матча.

## Privacy

В `growth_events` добавляется событие `news_ai_intent`.

В metadata сохраняется только технический режим CTA и безопасный team token. Заголовок статьи, URL, поисковая строка пользователя и произвольный текст новости не сохраняются.

Новая Supabase migration не нужна.

## Аналитика

Launch Funnel теперь различает:

- `news_open` — пользователь открыл новости;
- `news_ai_intent` — нажал AI-действие из новости;
- `news_return` — дошёл напрямую до конкретного матча из новости.

Админка показывает KPI «Новости → AI».

## Provider safety

Открытие общей новостной ленты не добавляет запросов API-Football. Для общей новости запрос к матчам возникает только после явного нажатия AI-кнопки пользователем и проходит через существующий search/cache flow.

## Production gate

RC69 требует:

- deterministic `newsConversionDrill`;
- regression test `telegram-news-conversion-rc69.test.js`;
- `npm run check`;
- полный test suite;
- `verify:release`;
- Wrangler dry-run;
- production post-deploy smoke.
